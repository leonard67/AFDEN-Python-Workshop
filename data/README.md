# `data/`

This folder contains all the datasets used by the workshop notebooks.

| File                            | Description                                                                                                                                   | Data source                                                                                                             |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `comp_sample.csv`             | Compustat annual fundamentals for a sample of firms.                                                                                          | Compustat (WRDS)                                                                                                        |
| `ccm.csv`                     | CRSP/Compustat Merged link table.                                                                                                            | CRSP/Compustat Merged link history (WRDS)                                                                               |
| `Sloan_Raw.dta`               | Firm-year panel of Compustat/CRSP-style financial-statement items and annual stock returns for the Sloan (1996) accrual-anomaly replication. | Compustat and CRSP (WRDS)                                                                                              |
| `Kothari_2025_data.xlsx`      | Multi-sheet workbook of the CMRA (capital-markets-research-in-accounting) database and macro time series.                                     | Replication data shared by the authors of Kothari et al. (2025)                                                         |
| `R&D_Keywords.txt`            | Plain-text list of R&D-related phrases (one per line) used to flag R&D-disclosure in 10-Ks.                                                   | R&D keyword list from Merkley (2014)                                                                                    |
| `StopWords_Generic.txt`       | Generic English stop-word list (121 words) used alongside the Loughran-McDonald dictionary.                                                   | Software Repository for Accounting and Finance, Univ. of Notre Dame                                                     |
| `sec_filing/`                 | Four raw 10-K filing text files.                                                                                                              | Software Repository for Accounting and Finance, Univ. of Notre Dame                                                     |
| `conference_call_transcript/` | Tesla earnings-call transcripts.                                                                                                              | Seeking Alpha                                                                                                           |
| `financial_phrasebank.csv`    | ~4,800 financial-news sentences hand-labeled positive / neutral / negative.                                                                   | Financial PhraseBank v1.0, Malo et al. (2014);`huggingface.co/datasets/takala/financial_phrasebank` (CC BY-NC-SA 3.0) |
| `BHP_Annual_report_2025.pdf`  | BHP Group FY2025 Annual Report.                                                                                                               | BHP Group                                                                                                               |
| `BHP_images/`                 | 43 images extracted from`BHP_Annual_report_2025.pdf` for the Gemini image-captioning exercise .                                             |                                                                                                                         |
